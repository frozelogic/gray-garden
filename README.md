## SOBRE A TRADUÇÃO

A tradução para o português brasileiro de [The Gray Garden](https://funamusea.itch.io/the-gray-garden) foi realizada por frozelogic. Os direitos sobre o texto traduzido, as imagens adaptadas e as modificações de arquivos pertencem ao tradutor.

O jogo original e todos os seus ativos são propriedade intelectual da criadora [Funamusea](http://funamusea.com/index.html). Nenhuma alteração de jogabilidade, mecânicas, scripts ou balanceamento foi efetuada. O escopo da intervenção limitou-se à adaptação de diálogos, descrições e elementos textuais, respeitando integralmente a obra original.

O projeto utilizou como base textual a [tradução para o idioma inglês](https://vgperson.com/games/graygarden.htm) disponível na Okegom Wiki. Nenhum diálogo, descrição ou elemento narrativo permaneceu em inglês; todo o conteúdo acessível ao jogador foi integralmente vertido para o português.

## SOBRE O USO DESTA TRADUÇÃO

Não é necessário solicitar permissão para utilizá-la em vídeos, gameplays ou transmissões. No entanto, exige-se a devida atribuição de créditos ao tradutor frozelogic, seja na descrição, nos comentários fixados ou no próprio conteúdo.

Para acessar todas as traduções disponíveis e seus respectivos links de download, utilize o site principal do tradutor: [frozelogic.carrd.co](https://frozelogic.carrd.co).

## SOBRE O FUNCIONAMENTO EM OUTRAS PLATAFORMAS

O projeto foi desenvolvido sem dependência do RTP 2000, portanto a instalação do Runtime Package do RPG Maker não é necessária. O jogo foi criado nativamente para Windows; para usuários deste sistema, basta descompactar o arquivo ZIP em um diretório de sua preferência e executar o jogo.

Para outras plataformas, recomenda-se o [EasyRPG Player](https://easyrpg.org/player/downloads/):

Em dispositivos móveis:\
• Crie uma pasta dedicada para os arquivos do EasyRPG Player.\
• Descompacte o conteúdo do ZIP do jogo dentro da subpasta games.\
• Caso a reprodução de MIDI não ocorra como esperado, baixe o [Default Windows MIDI Soundfont](https://musical-artifacts.com/artifacts/713), coloque o arquivo .sf2 dentro da pasta soundfonts e configure o EasyRPG Player para utilizá-lo.

No Mac ou Linux:\
• Você pode recorrer ao [WineBottler](https://winebottler.kronenberg.org/) (ou outra interface do Wine) para executar o arquivo original do jogo baseado em Windows.\
• Embora essa alternativa não tenha sido testada diretamente pelo tradutor, há grande probabilidade de que funcione sem impedimentos.
